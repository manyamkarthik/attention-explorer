What you're looking at
  • Each row of the matrix is one query token; the row is a softmax over the keys, so it sums to 1. Same thing the book prints as attn_weights, just coloured.
  • Simplified x·xᵀ is section 3.3: no trainable weights, just dot products of GPT-2's token embeddings. Every word mostly attends to itself. Trained Q·Kᵀ is 3.4–3.6 with real weights: 12 layers × 12 heads, each with its own Wq, Wk, Wv.
  • Layer 4, head 3 is the one that links it → animal. It was found by searching all 144 heads for the biggest weight, not picked by hand. Try the tired and wide examples: with the mask on, the row for it is identical, because it can't see the word that decides its meaning yet.
  • Turn the mask off and every token can read the future. GPT-2 was never trained that way, so it cheats: positions start predicting the word that's already sitting next to them (highlighted). That's why chapter 3 masks.
  • The first-token sink: heads with nothing useful to do dump attention on token 0. Hiding it renormalises each row over the other tokens.
